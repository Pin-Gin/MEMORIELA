## 3. Hero / MEMORIELA開発局 — 方針FIX

Heroは「MEMORIELA開発局」の世界観を最初に見せる場所。

### PC / Desktop

- 採用済み方向性: **ゆら + Pin銀 + 開発環境 / 開発局の横長一枚ビジュアル**。
- 以前の検討で採用した「開発局らしい横長Heroイメージ」を構図の基準とする。
- 右側に **LATEST TOPICS** を配置する。
- Hero内のナビ、TOPICS、更新可能な文字情報は画像へ焼き込まず、原則HTML/CSS側で実装する。
- PC Heroはこの方向性をFIX候補とし、大幅な再検討を増やさない。

### Mobile

- 縦長画面を活かし、**ドレス姿の久遠ゆら**をHeroとして使用する方向。
- PC画像を無理に縦トリミングしない。
- LATEST TOPICSは狭い画面に横並びで押し込まず、画像下または適切な縦レイアウトへ再配置する。

### Tablet

- **ラフな格好のゆら**で、開発局の緩い雰囲気を見せる専用Hero構想。
- ただし土曜公開時の必須条件ではない。
- 専用素材が間に合わない場合はPC Heroをレスポンシブ調整して代用し、公開後に差し替え可能な構造とする。

### 実装方式

- 接続元・端末情報をサーバー側で取得して分岐する方式を基本としない。
- CSS media query / responsive image / `<picture>` 等、画面幅ベースで切り替える。
- 現時点の正式構想は Desktop / Tablet / Mobile の3表情。ただし公開必須素材はDesktop + Mobile。

## 10. 画像生成に関する絶対ルール

**ホームページ作業中の新規画像生成は禁止。例外なく `image_gen` を呼ばない。**

- Hero、MASTER、レイアウト、配置、削除、差し替え、サイズ調整、画像参照はすべてWeb実装として扱う。
- 「この画像で」「これを使う」「このHeroで」「この構成で」「文字を消す」「画像を消す」は新規画像生成指示ではない。
- 素材不足でも勝手に画像を補完生成しない。
- MASTERを再生成しない。
- ユーザー依頼範囲外の「親切な追加生成」は禁止。
- 既存画像の編集は、ユーザーが画像そのものの編集を明示した場合のみ別タスクとして扱う。
- 新規画像生成を再び許可するには、ユーザーがホームページ作業とは別に「画像生成禁止を解除して、この画像を生成して」と明示する必要がある。

過去に画像生成の誤作動でホームページ作業時間を浪費したため、この項目は最優先の禁止事項として扱う。
