# MEMORIELA YouTube Operations

Status: **CANONICAL ROUTER**
Adopted: 2026-09-18
Scope: MEMORIELA公式YouTubeチャンネルの設立・動画制作・公開・運用

このディレクトリは、MEMORIELA公式YouTubeの制作と運用を新しいチャット／別AI／別編集ツールでも同じ基準で継続するための正本です。

## 1. Authority

YouTube関連の判断が競合した場合は、原則として次の順で優先します。

1. ユーザーの最新の明示的な確定判断
2. 本ディレクトリのMEMORIELA YouTube正本
3. Project YURAの保護された正本仕様
4. YouTubeの最新公式ポリシー・仕様
5. 現在利用する編集／生成ツールの仕様
6. 過去の案・AI自身の提案

YURAの人格・外見・設定をこのディレクトリで再定義しません。
YURAが登場する動画では、必ず `Pin-Gin/AI-Friend` の現行正本を参照します。

Primary Project YURA router:
`docs/assistant-context/YURA_START_HERE.md`

Project governance:
`docs/assistant-context/YURA_PROJECT_GOVERNANCE_RULES.md`

Visual identity:
`docs/assistant-context/visual-identity/`

## 2. Mandatory read order

YouTube動画の企画・制作・投稿を行う前に、必要な範囲で次を読みます。

1. `docs/youtube/README.md`
2. `docs/youtube/YOUTUBE_CHANNEL_MASTER.md`
3. `docs/youtube/YOUTUBE_PRODUCTION_RULES.md`
4. `docs/youtube/YOUTUBE_VIDEO_BRIEF_TEMPLATE.md`
5. 公開前に `docs/youtube/YOUTUBE_PUBLISH_CHECKLIST.md`

YURAが登場する場合は、上記に加えて `Pin-Gin/AI-Friend` の `YURA_START_HERE.md` から必要な正本を読みます。

## 3. Core principle

この運用の目的は「動画を量産すること」ではありません。

**MEMORIELA / Project YURAの世界観・人格・技術・開発過程を、一貫性と独自性を保ったまま外部へ伝えること**を優先します。

AIは制作速度を上げるために使いますが、動画ごとの企画意図・見せ場・情報価値・物語性を失うテンプレ量産にはしません。

## 4. Files

- `YOUTUBE_CHANNEL_MASTER.md`
  - チャンネルの固定情報・ブランド・役割
- `YOUTUBE_PRODUCTION_RULES.md`
  - 企画から編集・納品までの制作ルール
- `YOUTUBE_VIDEO_BRIEF_TEMPLATE.md`
  - ユーザーが動画制作を依頼するときの標準入力
- `YOUTUBE_PUBLISH_CHECKLIST.md`
  - 投稿前QA、権利、ポリシー、メタデータ確認

## 5. Change control

確定事項を変更する場合は、変更理由と日付を正本へ反映します。
一時的な動画固有の演出を、チャンネル全体の恒久ルールへ昇格させません。
YouTube側の仕様・ポリシーのような外部依存情報は、必要時に公式情報を再確認します。
