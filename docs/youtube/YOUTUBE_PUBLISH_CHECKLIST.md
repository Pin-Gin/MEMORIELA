# MEMORIELA YouTube Publish Checklist

Status: **CANONICAL / MANDATORY BEFORE PUBLICATION**
Adopted: 2026-09-18
Platform-policy verification baseline: 2026-09-18

公開前に、このチェックを動画単位で実施します。

## 1. Content

- [ ] 動画の目的が明確
- [ ] 冒頭と本編の内容が一致
- [ ] 本編に動画固有の価値がある
- [ ] 不要な重複・間延びがない
- [ ] 生成破綻・誤字・不自然なカットがない
- [ ] YURAが登場する場合、人格・外見・設定が正本と整合
- [ ] 古いMASTERや旧ブランドを誤って使用していない

## 2. Brand

- [ ] `MEMORIELA` 表記確認
- [ ] `Project YURA` / `Project.YURA` は使用箇所の正式表記に従っている
- [ ] `久遠ゆら / YURA` の表記確認
- [ ] URL・SNS・ハンドルが正しい
- [ ] 公式を装う第三者素材が混入していない

## 3. Copyright / rights

- [ ] 映像素材の権利確認
- [ ] 画像素材の権利確認
- [ ] BGMの権利確認
- [ ] SEの権利確認
- [ ] フォントの動画利用条件確認（必要な場合）
- [ ] 外部キャラクター・ロゴ・商品・映像の使用根拠確認
- [ ] 他者の声・肖像の利用許諾確認
- [ ] 必要なクレジットを記載
- [ ] 出所不明素材を使用していない

著作物の利用について「少し変えたから大丈夫」「短時間だから大丈夫」とは判断しません。
必要時は権利者許可、ライセンス、YouTube Audio Library等を使用します。

Official reference:
https://support.google.com/youtube/answer/2797466

## 4. AI / synthetic content

- [ ] AI生成・改変を内部制作記録へ残した
- [ ] 実在人物がしていない発言・行動をリアルに見せていないか確認
- [ ] 実在の場所・出来事を現実映像のように改変していないか確認
- [ ] 現実には起きていないリアルな場面を生成していないか確認
- [ ] 該当する場合、YouTube StudioのAI/altered content disclosureを設定
- [ ] AI生成された第三者の顔・声で本人の承認を偽装していない

YURA等の架空キャラクターをAIで制作したという事実だけで、自動的に同一の開示判断にはしません。
YouTubeの最新公式要件を動画ごとに適用します。

Official reference:
https://support.google.com/youtube/answer/14328491
https://support.google.com/youtube/answer/15447836

## 5. Metadata

- [ ] タイトルが動画内容と一致
- [ ] サムネイルが動画内容と一致
- [ ] 説明欄が正確
- [ ] 誤解を招く煽りがない
- [ ] 関係ない検索語を入れていない
- [ ] URLが正しい
- [ ] 必要なクレジットがある
- [ ] 必要なAI開示・説明がある
- [ ] ハッシュタグは関連するものだけ

Official reference:
https://support.google.com/youtube/answer/2801973

## 6. Originality / repetitive-content check

- [ ] 過去動画と実質的に同じ内容の量産になっていない
- [ ] テンプレを使う場合でも本編の価値が十分異なる
- [ ] 独自の解説・ストーリー・情報・演出・デモのいずれかがある
- [ ] 外部動画の再利用だけで成立していない
- [ ] AIで短時間大量生成しただけの動画になっていない

YouTubeはオリジナルでauthenticなコンテンツを収益化上重視し、量産的・反復的・独自性の乏しいコンテンツを対象外とする場合があります。

Official reference:
https://support.google.com/youtube/answer/1311392

## 7. Technical QA

投稿時点のYouTube公式仕様を必要に応じて確認します。

- [ ] 画面比率
- [ ] 解像度
- [ ] 音声
- [ ] フレームレート
- [ ] エンコード
- [ ] 字幕
- [ ] サムネイル
- [ ] Shorts判定条件
- [ ] ファイル再生確認
- [ ] スマホでの可読性
- [ ] PCでの見え方

YouTube依存の数値仕様は、本チェックリストへ恒久値として固定しません。

## 8. Final review

- [ ] draftではなく公開候補版
- [ ] ユーザー確認が必要な変更を勝手に加えていない
- [ ] 外部公開して問題ない情報だけが含まれる
- [ ] 開発用秘密情報・API key・個人情報・内部URL・非公開画面が映っていない
- [ ] 公開後に公式HP / Xとの表記矛盾がない
- [ ] ユーザーの最終公開承認あり

## 9. Publish record

公開後、必要に応じて以下を記録します。

- video title
- YouTube URL
- publish date
- format
- series
- source project / feature
- major assets
- production tools
- rights notes
- relevant decision / exception

## 10. Policy freshness

YouTubeポリシー・UI・仕様は変更されます。
権利・AI開示・収益化・Community Guidelines・アップロード仕様について重要な判断をする場合は、過去の記憶ではなくYouTube公式情報を再確認します。
