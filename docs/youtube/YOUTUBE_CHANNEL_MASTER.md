## 2. Channel role

MEMORIELA公式YouTubeは、単なる広告チャンネルではなく、以下を外部へ見せる公式メディアとして扱います。

- Project YURAの開発・進化
- YURAというキャラクター／AIの魅力
- 3D YURA、将来のLive2D等を含む表現
- 技術デモ・開発記録
- YURAの日常・物語・短編コンテンツ
- MEMORIELAの世界観
- 必要に応じた解説・告知

動画ごとにすべてを盛り込む必要はありません。
各動画は「何を一つ伝える動画か」を明確にします。

## 3. Content families

現時点での分類です。新シリーズを確定した場合はここへ追加します。

### A. Shorts / discovery
短時間でYURAの存在・表情・動き・世界観を伝える入口。

### B. Development log
開発記録、アップデート、比較、技術的な変化を見せる。

### C. Character / story
YURA自身を主役にした日常・会話・短い物語・演出。

### D. Feature / showcase
3D化、UI、Memory、Relationship等の特定機能を見せる。

### E. Announcement
サイト公開、重要アップデート、イベント等の告知。

## 4. Brand consistency

YURAの人格・ビジュアル・設定はYouTube用に別人格化しません。
動画向け演出を追加しても、Project YURAの正本を上書きしません。

YURAが登場する場合:

- 人格 → Project YURA正本
- ビジュアル → Visual Identity正本
- 衣装・ポーズ・表情 → 正本からの派生
- 世界観固有設定 → 確定済み資料を優先

動画都合でYURAの性格・口調・容姿を変更する必要がある場合は、派生演出なのか正式設定変更なのかを明確に分けます。
