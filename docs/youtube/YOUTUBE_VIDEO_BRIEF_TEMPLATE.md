## Minimal request

最短では次の4項目だけでも開始できます。

```text
目的:
形式: Shorts / 長尺 / 未定
見せたいもの:
絶対に変えたくないこと:
```

例:

```text
目的: 3D化したYURAの初披露
形式: Shorts
見せたいもの: 振り返って笑うYURA
絶対に変えたくないこと: YURAの顔と髪、落ち着いた雰囲気
```

## AI conversion rule

ユーザーが自然文で依頼した場合、AIは内容を上記briefへ整理します。

ただし:

- 書かれていない設定を確定扱いしない
- YURA正本と競合する内容を自動採用しない
- 動画固有の演出を恒久設定にしない
- ユーザーの目的を勝手に広告目的へ変えない

制作前にユーザー確認が有益な場合はbriefを提示できます。
ユーザーが即制作を求めている場合は、内部briefとして使用して作業を進めます。
