## Historical layout characteristics to preserve as reference

When using this material during future Background formalization, treat the following as previously approved layout evidence rather than current protected authority:

- same overall room geometry and camera-facing layout
- bed on the right side
- desk / work area on the left side
- large central balcony/window opening
- same principal shelves and furniture placement
- same warm wood flooring
- same soft white / greige / muted-gray palette
- same mix of books, plants, delicate decor, soft textiles, lace and restrained ribbon motifs
- same refined, calm, lived-in atmosphere

Minor object-level variation caused by image generation is acceptable, but derivatives should not become a visibly different room.

## Historical background-only guidance

At the time of the original room concept, background-only assets were intended to be generated without:

- people
- character silhouettes
- readable text
- logos
- captions

## Historical planned derivatives

The intended room background set is:

1. `YURA ROOM / MORNING`
   - derived from DAY
   - preserve room/furniture layout
   - morning light and cooler/cleaner early-day atmosphere

2. `YURA ROOM MASTER / DAY`
   - canonical baseline

3. `YURA ROOM / EVENING`
   - derived from DAY
   - preserve room/furniture layout
   - darker exterior and warm interior practical/indirect lighting

4. `YURA ROOM / SLEEP`
   - derived from the same room
   - bed-focused framing
   - low nighttime illumination / bedside-light mood
   - used specifically for bedtime / sleep scenes

## Derivative generation rule

For MORNING, EVENING, or SLEEP variants:

1. use the approved DAY master image as the image reference whenever possible;
2. edit lighting, time of day, exterior brightness, and requested framing only;
3. do not redesign the room from text alone when the DAY master can be supplied;
4. for SLEEP, a tighter bed-focused composition is allowed while preserving recognizable room details;
5. generated derivatives do not replace this DAY master unless explicitly approved.
