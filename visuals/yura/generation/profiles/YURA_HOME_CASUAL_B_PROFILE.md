# YURA 家用ラフ服装 B案 — 生成用デフォルトプロファイル

Status: **ACTIVE DEFAULT FOR GENERATION / DESIGN PROVISIONAL / NOT A VISUAL MASTER**
Author instruction date: 2026-10-21

## 1. Purpose / Trigger

作者が「ラフな服装」と指定し、他に衣装の詳細・別衣装の指定がない場合、このB案の衣装構成を**デフォルトで適用する**。
「家で過ごすラフな服装」も同様。場面や背景だけを理由に衣装を別のものへ置き換えない。
ただし、作者がその都度別の衣装・色・素材・丈・靴を明示した場合は、**その明示指定を優先**する。

本書は衣装の**生成用プロファイル**。作者がここまで選んだ方向性を次回以降も再利用するための記録であり、衣装の最終Master画像や全ディテールの確定を意味しない。未定義のデザイン細部を勝手に「正式確定」としない。

## 3. Silhouette / layering checks

- 前開きのカーディガンから白のノースリーブインナーが見える。
- カーディガンの裾とハーフパンツの裾を同じ位置に揃えない。**ハーフパンツの裾を下に見せる**。
- ロング丈は「上半身が伸びる」ことを意味しない。衣服の布丈と身体の胴長を混同しない。
- ゆったりしたカーディガンの生地の余裕を、肩幅・胸郭・腕・ウエストなど身体そのものの拡大として扱わない。
- インナーとカーディガンの重なり、布のたるみ・陰影があっても、身体基準の胸部位置と左右バランスを変形させない。
- ハーフパンツの布のゆとりを、腰・太腿の体格変更と混同しない。

## 5. Variables not fixed by this profile

- 髪型（シニヨン・ローツインテール等）は**生成ごとの作者指定**および既存髪型ルールで決める。本書は髪型を変更・固定しない。
- カーディガンの前立て、ボタンの具体的仕様、ポケットの有無、袖口・裾の細かな仕上げは未確定。
- インナーの細かな襟ぐり寸法・フリルの幅、パンツ丈の数値・正確なパイピング幅は未確定。
- 色番号（HEX等）は確定していない。青白系の印象を維持して過度な彩度にしない。
- 衣装Master画像は未作成。画像生成結果は候補であり、作者の明示PASSによるMaster昇格は別途必要。
