# YURA VALIDATION CLOTHING

Status: **FIXED COMPARISON CONDITION**

Purpose: BODY / HAIR / pose / master-candidate validation with minimal clothing interference.

## Upper
- pale / off-white / light-neutral
- plain
- opaque
- matte
- simple sleeveless top
- **broad shoulder sections; not thin straps**
- natural fit
- hem around waist / hip-bone region
- no ornament

## Lower
- pale / off-white / light-neutral
- plain simple shorts
- opaque
- matte
- upper-thigh length
- no ornament
- **no drawstring**
- no lace / frills / bows / logos

## Common
- barefoot
- white / warm-white background
- no jewelry
- no hair ornament
- exactly one YURA
- clothing follows BODY; never reshape BODY to fit clothing

## Prompt block
淡色・無地・不透明・マットな幅広肩のシンプルなノースリーブトップス。淡色・無地・不透明・マットな装飾なし・ドローコードなしのシンプルなショートパンツ。裸足。白背景。

## FAIL
Comparison-condition FAIL if:
- thin camisole straps
- ribbons / bows
- lace / frills
- drawstring
- sheer fabric
- deep neckline used to alter body readability
- fashion styling that materially changes BODY readability

A clothing mismatch is not automatically BODY failure.
