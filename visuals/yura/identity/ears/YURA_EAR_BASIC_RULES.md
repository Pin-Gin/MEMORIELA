# YURA EAR BASIC RULES

Status: **AUTHOR-DIRECTED / SUPPORTING VISUAL RULE / ACTIVE FOR EAR MASTER WORK**

## Authority

`visuals/yura/identity/master/YURA_VISUAL_TEXT.md` is the highest and absolute YURA visual text authority.

This file is a focused supporting rule for ear work only. If this file conflicts with `YURA_VISUAL_TEXT.md`, the Visual Text wins and generation must stop rather than silently reconcile the conflict.

For current face geometry, also follow:

`visuals/yura/identity/specs/YURA_FACE_REDESIGN_SPEC.md`

## Purpose

Prevent generation from making the ears longer, larger, more outward, or more exposed merely so they are easy to see.

Separate:

```text
EAR ACTUAL GEOMETRY
EAR VISIBLE GEOMETRY
HAIR OCCLUSION
```

Visibility is not geometry.

## Ear actual geometry

```text
TARGET HEIGHT = 20–22% of face vertical dimension
HARD MAX      = 23%
```

- vertically compact
- slightly small / low-prominence
- close to the side of the head
- no outward flare
- no camera-facing rotation for visibility
- do not compensate for reduced height by increasing width

Placement guides:

- upper attachment: approximately eye height
- lower attachment: approximately below the nose / nose-base region
- overall top: approximately around eyebrow height as an upper landmark

These are placement guides, not a command to stretch the ear between landmarks.

```text
COMPACT EAR HEIGHT WINS.
```

## Visibility / non-compensation

The ear does not need to be easy to read.

Allowed:

- partial visibility
- a very small visible fragment
- asymmetric visibility
- zero visible ear when naturally occluded

Forbidden merely to improve ear visibility:

- lengthening the ear
- widening the ear
- moving it outward
- rotating it toward camera
- pushing it outside the hair mass
- clearing natural hair around it
- moving face-framing strands behind it
- forcing left/right equal visibility

```text
EAR VISIBILITY SHORTAGE = NOT A FAILURE.
NO VISIBILITY COMPENSATION.
```

## Hairless ear-geometry Master stage

A temporary hairless face-up image is allowed only as an **ear-geometry diagnostic / structural Master carrier**.

This does not redefine YURA's hair identity and is not a normal appearance image.

During this stage:

- preserve the approved face geometry exactly;
- do not lengthen, narrow, mature, or otherwise redesign the face;
- do not change eye placement, eye shape, cheeks, jaw, chin, nose, mouth, or neutral-expression baseline;
- remove hair only so the complete ear geometry can be inspected without occlusion;
- do not infer a new scalp, hairstyle, or production hair rule from the hairless diagnostic image;
- judge ear size and placement from actual geometry, not from a need for readability.

A generated hairless image remains a candidate until explicit author PASS and promotion.

Intended promoted path after author approval:

`visuals/yura/identity/ears/YURA_EAR_GEOMETRY_MASTER.png`

## Face-up Master stage with hair restored

After the ear-geometry Master is approved, generate the normal face-up using:

- current `YURA_VISUAL_TEXT.md`;
- current face redesign specification;
- approved ear-geometry Master as ear-structure support;
- YURA's normal hair restored from Visual Text.

Natural hair occlusion is preferred over exposing the ear.

Do not move hair to prove that the ear exists.

The complete ear outline does not need to be visible. The top and bottom do not need to be simultaneously readable.

Intended promoted path after author approval:

`visuals/yura/identity/face/YURA_FACE_UP_MASTER.png`

## Hard failures

FAIL when any of the following occurs:

- ear reads clearly too long or vertically stretched;
- actual ear exceeds the hard maximum;
- ear is moved outward or rotated toward camera for visibility;
- ear width increases as compensation for reduced height;
- hair is rearranged only to expose the ear;
- face geometry changes while correcting the ear;
- neutral face expression drifts to smile, sadness, worry, wistfulness, or melancholy.
