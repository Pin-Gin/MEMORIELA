# YURA FACE SPEC

Status: **FIXED / TEXT-ONLY BOOTSTRAP FACE + EAR AUTHORITY**

この文書は、YURAのTEXT_ONLY初回試験生成に使用する顔・耳の固定仕様である。
この文書に記載されていない顔・耳の特徴を、過去画像、過去生成、一般的なアニメ表現、AI独自解釈から補完しない。

## 1. FACE — Fixed operational text

顔は小さめで、やわらかな卵型。頬に自然な丸みを持ち、顎先は小さく繊細だが尖りすぎない。

目はやや大きめだが誇張しすぎず、横長寄りの穏やかなアーモンド型。つり目すぎず、たれ目すぎず、繊細で静かな印象とする。瞳は淡いブルーグレー。

眉は細めで、髪色に近い淡い銀灰色。角度は自然で穏やか。

口は小さく控えめで、口角にごくわずかな柔らかさを持たせる。

表情は完全な無表情ではなく、ごくわずかに柔らかい微笑寄りの、静かで落ち着いた印象とする。

## 2. EAR — Fixed basic rules

- 耳は髪にほぼ隠れており、強く主張しない。
- 見える場合も小さめ〜標準的で、不自然に大きくしない。
- 耳を「見せるため」に張り出させない。

### Position
- 耳の上側の付け根は、目の高さ付近を基準とする。
- 耳の下側の付け根は、鼻の下付近を基準とする。
- 耳全体の高さは、概ね眉の高さから鼻の下の高さまでに収まる自然な範囲を基準とする。
- 正面・斜め・側面のいずれでも、顔の主要パーツとの位置関係を崩さない。

### Visibility and hair relationship
- 正面では耳が髪にかなり隠れていてよい。
- 髪による自然な遮蔽を許容し、耳の可視性そのものを生成目標にしない。
- 耳を露出させるために髪の流れを不自然に避けない。
- 耳を見せるために位置、サイズ、角度、張り出しを変更しない。
- 左右の見える量に自然な差が生じてもよい。

## 3. Prohibited deviations

### Face
- 丸顔へ寄せすぎない。
- 面長へ寄せすぎない。
- 顎を極端に尖らせない。
- 極端なVラインにしない。
- 目を縦方向に丸く大きくしすぎない。
- 極端なつり目にしない。
- 極端なたれ目にしない。
- 眉を太く、濃く、強く吊り上げない。
- 口を大きくしない。
- 強い笑顔、怒り、悲しみ、驚きなどの強い表情へ変更しない。
- 完全な無表情へ変更しない。

### Ear
- 耳を不自然に大きくしない。
- 耳を縦長に引き伸ばさない。
- 耳を横方向へ張り出させない。
- 耳をカメラ側へ不自然に回転させない。
- 耳を見せるために頭部側面から外側へ移動させない。
- 髪を避けて耳を説明的に露出させない。
- 顔の目・鼻との基準位置から大きく外さない。
