# YURA FACE SPEC

Status: **FIXED / TEXT-ONLY BOOTSTRAP FACE + EAR AUTHORITY**

この文書は、YURAのTEXT_ONLY初回試験生成に使用する顔・耳の固定仕様である。  
この文書に記載されていない顔・耳の特徴を、過去画像、過去生成、一般的なアニメ表現、AI独自解釈から補完しない。

## 1. FACE — Fixed operational text

顔は小さめで、可愛らしさを主体としたやわらかな卵型。  
印象の比重は、**可愛い70%、綺麗30%** を基準とする。

頬にはやや自然な丸みを持たせる。  
下顔面はコンパクトで、顎先は小さく繊細だが尖りすぎない。  
全体として、整いすぎた美人顔ではなく、やさしく愛らしい印象を優先する。

目はやや大きめだが誇張しすぎず、横長寄りの穏やかなアーモンド型。  
つり目すぎず、たれ目すぎず、やさしく可愛らしい印象とする。  
縦に丸すぎる目にはしないが、冷たく見える細すぎる目にも寄せない。  
瞳は淡いブルーグレー。

眉は細めで、髪色に近い淡い銀灰色。  
角度は自然で穏やかで、きつく見せない。

口は小さく控えめで、口角にごくわずかな柔らかさを持たせる。  
主張しすぎず、やさしく可愛らしい口元とする。

表情は完全な無表情ではなく、  
ごくわずかに柔らかい微笑寄りの、静かでやさしい印象とする。  
落ち着きは保つが、綺麗すぎる無機質さには寄せず、親しみのある可愛らしさを優先する。

## 2. EAR — Fixed basic rules

### Size priority

耳は髪にほぼ隠れており、強く主張しない。

耳のサイズ維持を、耳の可視性および位置合わせより優先する。  
迷った場合は、耳を長くするのではなく、短く小さめに保ち、必要なら髪で隠す。

耳の実形状は小さめを基準とする。  
額上部から顎先までの顔の縦寸法を100%とした場合、  
耳の縦寸法は**約20〜24%** を基準とする。  
**1/4を大きく超えない。**  
**約1/3まで長くしない。**

耳を見せるため、位置を合わせるため、または顔の構造を分かりやすくするために、  
耳を縦方向へ拡大してはならない。

### Position

耳の上側の付け根は、目の高さ付近を基準とする。  
耳の下側の付け根は、鼻の下付近を目安とする。

ただし、これらは耳の配置位置を判断するための目安であり、  
耳そのものを縦に長くしてこの領域へ合わせることを意味しない。

耳の位置合わせによって、保護された耳の縦寸法を変更しない。

### Front-view lock

正面視では耳の可視性より、小さな耳形状の維持を優先する。

耳は髪にかなり隠れていてよい。  
耳全体が見える必要はない。  
上部または下部が髪で隠れてよい。  
正面で見える耳は、一部分のみでもよい。

正面から耳を見せるために、  
耳を長くしない。  
耳を大きくしない。  
耳を外側へ移動させない。  
耳を横へ張り出させない。  
耳をカメラ側へ回転させない。

可視部分が小さい場合でも、  
その可視性を補うために耳全体を縦方向へ拡張しない。

### Visibility and hair relationship

髪による自然な遮蔽を許容する。  
耳の可視性そのものを生成目標にしない。  
耳を露出させるために髪の流れを変えない。  
左右の耳の見える量に自然な差が生じてもよい。

## 3. Prohibited deviations

### Face
- 丸顔へ寄せすぎない。
- 面長へ寄せすぎない。
- 顎を極端に尖らせない。
- 極端なVラインにしない。
- 綺麗さを優先しすぎて、可愛らしさが後退する顔にしない。
- 幼すぎる幼顔に寄せすぎない。
- 目を縦方向に丸く大きくしすぎない。
- 冷たく見えるほど細い目にしない。
- 極端なつり目にしない。
- 極端なたれ目にしない。
- 眉を太く、濃く、強く吊り上げない。
- 口を大きくしない。
- 強い笑顔、怒り、悲しみ、驚きなどの強い表情へ変更しない。
- 完全な無表情へ変更しない。
- 無機質で感情の乏しい美人顔へ寄せすぎない。

### Ear
- 耳を不自然に大きくしない。
- 耳を縦長に引き伸ばさない。
- 耳を横方向へ張り出させない。
- 耳をカメラ側へ不自然に回転させない。
- 耳を見せるために頭部側面から外側へ移動させない。
- 髪を避けて耳を説明的に露出させない。
- 顔の目・鼻との基準位置から大きく外さない。
- 正面視で耳の上端から下端までを完全露出させる必要はない。
- 位置基準を耳の縦寸法として解釈しない。
- 耳の位置合わせを理由に縦方向へ拡大しない。
- 耳が小さく見えにくい場合でも、可視性を理由に長くしない。
