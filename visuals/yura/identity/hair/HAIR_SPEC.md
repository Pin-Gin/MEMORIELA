# 久遠ゆら HAIR SPEC

Status: **PROTECTED / CURRENT / HARD-LOCKED**

## Default source hairstyle
Default = **Normal Super-Long / down hair**.

Unless the user explicitly requests another hairstyle, always use:
`styles/NORMAL_SUPER_LONG.md`

## Critical interpretation rule
The label **"Super-Long" is only the hairstyle category name.**

It is **NOT permission to use generic anime "very long hair" length**.

Exact YURA length is controlled only by:
`styles/NORMAL_SUPER_LONG.md`

If generic model knowledge conflicts with that file, the protected YURA length wins.

## HARD LOCK — color
Hair identity:
`SILVER-WHITE ONLY`

Required:
- silver-white
- cool-neutral direction
- white-leaning with subtle cool gray / silver nuance

Do not shift to:
- beige
- blonde
- cream-blonde
- lavender
- pink-lavender
- metallic silver

Scene lighting may tint highlights slightly but must not recolor identity.

## HARD LOCK — source properties
- individual strands: fine and soft
- total mass: standard to slightly above standard
- fine does not mean sparse
- upper hair settles under its own length / weight
- grouped anime hair masses remain readable
- restrained lateral spread
- gravity-dominant fall
- main mass remains centered behind / around the back rather than being moved mostly forward

Do not increase total mass merely because the hair is long.
Do not make the hair fan widely sideways.

## Bangs / face framing
- thin long bangs
- soft separated fringe
- forehead not completely blocked
- long cheek-framing side sections
- eyes remain readable
- no ornaments / braid / bun unless explicitly requested

Local bangs / side-hair placement around the ears may vary naturally.
Ear visibility is not a target: the ear may be visible, partly hidden, or fully hidden.
Do not change source hair length, total mass, color, or hairstyle identity merely for ear visibility.

## Length authority
All exact default length rules come from:
`styles/NORMAL_SUPER_LONG.md`

That file is mandatory.

## Hair conservation under pose
Pose may change:
- gravity direction
- overlap
- body / furniture contact
- local flow
- occlusion

Pose must not change:
- source total mass
- source length
- silver-white identity
- source topology
- default hairstyle

Do not:
- shorten hair because seated
- lengthen hair because crouched
- move most hair forward merely to expose joints / chest
- delete back mass during a bend
- widen the hair curtain merely to show BODY

## Optional hairstyles
Only load when explicitly requested:
- `styles/LOW_CHIGNON.md`
- `styles/strong-braided-half-up/SPEC.md`

Optional hairstyle rules never redefine the default source hair.

## FAIL boundaries
HAIR FAIL if materially present:
- generic thigh-length "super-long" reinterpretation
- main dense hair mass extends to mid-buttock or below
- blonde / beige / lavender color drift
- sparse hair caused by interpreting "fine" as low mass
- large fan-shaped lateral spread
- back mass moved mostly to the front
- eyes heavily covered
- source hair length / total-mass / identity change driven by ear visibility
- pose-dependent source length / total-mass change
