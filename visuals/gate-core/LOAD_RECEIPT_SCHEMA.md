# VISUAL GENERATION LOAD RECEIPT SCHEMA

Status: **MANDATORY BEFORE GENERATION**

Use this schema before every protected Visual generation.

```text
[GENERATION LOAD RECEIPT]

REFERENCE_POLICY:
IDENTITY_ROOT_REFERENCE:
FACE_DETAIL_REFERENCE:
BODY_VIEW:

UNAUTHORIZED_REFERENCES: NONE / ...
MISSING_AUTHORITIES: NONE / ...
AUTHORITY_CONFLICTS: NONE / ...

VISIBILITY_OCCLUSION_PROTOCOL: PASS/FAIL
SHOW_FEATURE_COMPENSATION: DENIED
AI_INFERENCE_REQUIRED: NONE / ...
USER_AUTHORIZED_VARIATION: NONE / ...

GENERATION_ALLOWED: YES/NO
```

`GENERATION_ALLOWED = YES` only when all mandatory checks for the active mode/submode PASS.

For an explicitly text-only submode:
- `REFERENCE_POLICY = NONE`
- all generation-time visual reference fields must be `NONE`
- `ACTUAL_VISUAL_REFERENCES_AVAILABLE = NOT_REQUIRED`
