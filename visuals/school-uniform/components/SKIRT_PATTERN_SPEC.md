# SCHOOL UNIFORM SKIRT PATTERN SPEC

Status: **PROTECTED / CURRENT**

## Pattern
- base: black
- grid / line accent: dark muted red
- restrained check
- pleated school-skirt construction
- regular pleat rhythm

## Forbidden additions
- white grid
- gray dominant grid
- bright red blocks
- green tartan accents
- beige accents
- extra decorative colors
- asymmetrical hem
- frill / lace trim

The approved Female Uniform Master will become the primary visual pattern anchor after adoption.
