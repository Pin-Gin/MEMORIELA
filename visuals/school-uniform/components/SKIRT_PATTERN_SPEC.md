# SCHOOL UNIFORM SKIRT PATTERN SPEC

Status: **PROTECTED / CURRENT**

Visual anchor:
`../master/female/FEMALE_UNIFORM_MASTER.png`

## Pattern
- base: black to near-black
- dominant grid / line accent: dark muted red
- restrained dark check
- multiple red line weights may appear as in the Master
- pleated school-skirt construction
- regular pleat rhythm
- pattern continues coherently across pleats

## Shape
- standard pleated skirt
- clean hem
- no asymmetrical hem
- no frill / lace

Canonical school length is governed by `../SCHOOL_UNIFORM_SPEC.md`.
The mannequin body in the Master is not a measurement authority for character anatomy or exact apparent knee distance.

## Forbidden additions
- white dominant grid
- gray dominant grid
- bright red blocks
- green tartan accents
- beige accents
- extra decorative colors
- asymmetrical hem
- frill / lace trim
- plain solid skirt replacing the check

The approved Female Uniform Master is the primary visual pattern anchor.
