# SCHOOL UNIFORM REFERENCE GATE

Status: **PROTECTED / MANDATORY**

Uniform Master is:
`OUTFIT_REFERENCE`

It may control:
- garment silhouette
- garment construction
- piping
- buttons
- ribbon / tie
- skirt / slacks
- check pattern
- emblem placement / design
- canonical uniform color appearance

It must not control:
- character BODY proportions
- bust / ribcage / waist / pelvis
- FACE
- EYE
- HAIR
- SKIN
- character age appearance
- pose
- rendering identity

A mannequin in the Uniform Master is only a display support.

Git existence alone is not sufficient. The actual approved Master must be available to image-generation execution.

Missing approved Master in PRODUCTION = FAIL.
