# SCHOOL UNIFORM QA

Status: **CANONICAL / CURRENT**

Evaluate uniform independently from character identity.

## Gate 1 — Blazer
- slightly dark muted brown
- black piping
- restrained gold buttons
- no navy / charcoal substitution

## Gate 2 — Grade color
- second-year accent = red
- female ribbon red
- male tie red

## Gate 3 — Female skirt
- black base
- dark muted red check lines
- pleated construction
- no unauthorized accent colors

## Gate 4 — Emblem
- wearer's left chest
- viewer-right in front view
- no invented text / motif before Master transcription

## Gate 5 — BODY isolation
PASS only if garment follows the character's protected BODY.
FAIL if the mannequin / garment reference changes character anatomy.

## Gate 6 — Reference integrity
PRODUCTION requires approved OUTFIT_REFERENCE actually available to execution.

## Decision
- PASS
- TARGETED RETRY: uniform scope only
- REJECT: material uniform-authority or reference failure

Uniform failure must not trigger character FACE / BODY redesign.
